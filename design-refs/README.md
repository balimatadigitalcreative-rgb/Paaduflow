# Design References

Taruh seluruh export Claude Design (`.html`) di folder ini.

**Folder ini adalah referensi, bukan kode.** Tidak ada file di sini yang boleh
diimpor oleh aplikasi. Isinya HTML statis dengan inline style — berguna untuk
membaca struktur dan hierarki visual, bukan untuk disalin.

Konvensi penamaan: `<Modul>_<Screen>.html`

```
design-refs/
├── Paadu_Flow_System_States.html
├── Paadu_Flow_Dashboard.html
├── Sales_Invoice_List.html
└── Settings_Permissions.html
```

Prosedur konversi ada di `CLAUDE.md` di root. Template prompt siap-pakai ada di
`PROMPTS.md`.
