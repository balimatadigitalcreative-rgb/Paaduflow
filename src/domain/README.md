# Domain

Entitas dan aturan bisnis murni. **Tidak boleh mengimpor framework, basis data, atau HTTP.**

Isinya: entitas (Invoice, StockMovement, Journal), value object (Money, TaxCode), aturan transisi status, dan perhitungan yang tidak bergantung teknologi apa pun.

Uji di sini harus dapat berjalan tanpa basis data.
