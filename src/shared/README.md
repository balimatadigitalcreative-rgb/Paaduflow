# Shared

Kernel bersama. Hal yang dipakai lebih dari satu modul **dan** tidak dimiliki modul mana pun: tipe identitas, `Money`, hasil-atau-galat, waktu, dan kosakata lintas modul seperti tiga sumbu status dokumen.

Aturannya ketat: sesuatu masuk ke sini hanya setelah dibutuhkan di **dua** modul. Folder ini adalah tempat paling mudah untuk diam-diam menjadi tempat sampah, dan isinya tidak dapat dilepas kembali tanpa menyentuh semua modul.

Shared tidak mengimpor lapisan mana pun — ditegakkan `tools/eslint-rules`.
